# L3. 품질 요구 명세

| 항목 | 내용 |
|---|---|
| 버전 | v1.0 (초안) |
| 작성일 | 2026-07-15 |
| 답하는 질문 | 시스템이 무엇을 만족해야 하는가 (설계 전에 확정하는 조건들) |
| 답하지 않는 질문 | 어떻게 만족시키는가(L4), 만족을 어떻게 상시 측정하는가(L5) |
| 입력 | L2의 CAP-1~9, L1의 A1~A10, L0의 약속 3개와 H1a~H4 |

---

## 0. 작성 규칙

1. **절대 보장형 문장 금지.** 외부 LLM API에 의존하는 경로의 품질은 "항상/반드시/0건"으로 쓸 수 없다. 모든 조건은 **예산(검증 가능한 수치나 기준) + 위반 감지 방법 + 위반 시 강등 경로**의 3종 세트로 쓴다.
2. **예외: 결정적 경로.** LLM을 거치지 않는 영역(저장, 상태 판정, 표시)은 우리 통제 안이므로 절대형을 허용한다.
3. 수치는 PoC 기준값이다. 도그푸딩 실측 후 조정할 수 있으나, 조정은 이 문서의 개정으로만 한다.

## 1. 품질 조건

### Q1. 응답 시간

| 조건 | 예산 | 위반 감지 | 강등 경로 |
|---|---|---|---|
| 첫 반응 (진행 표시 첫 줄) | 1초 이내, 항상 (결정적 경로 - 외부 모델 비의존으로 설계) | 제출~첫 표시 시간 기록 | 해당 없음 (설계로 보장) |
| 즉답형 응답 | 5초 이내 | 응답 시간 기록 | 초과 시 분석형으로 전환하고 진행 표시 시작 |
| 분석형 응답 | 반복 실행의 90%가 40초 이내 | 응답 시간 기록 | 단계별 시간 초과 시 해당 조사를 미완료 처리하고 부분 결과로 답변 (L2 §6.4) |

근원: CAP-3, H4, L2 §6.

### Q2. 근거 충실

| 조건 | 기준 | 위반 감지 | 강등 경로 |
|---|---|---|---|
| 화면 도달 답변의 모든 인용은 원본 데이터에 실존한다 | 도달 기준 위반 0 | 도달 전 대조 검증: 인용 식별자가 이번 조사의 반환값에 존재하는지 기계 대조 | 위반 시 재생성 최대 2회, 소진 시 해당 주장을 제거하거나 "모른다" 응답으로 강등 |
| 근거 부족 주제에는 조언을 생성하지 않는다 | 도달 기준 위반 0 | 조사 반환값이 빈 경우의 응답 유형 검사 | 위반 시 위와 동일 |

근원: CAP-8, H3, R1·R6. "생성 단계의 환각 0"이 아니라 "도달 0"임에 주의 (L0 §6.1).

### Q3. 형식 준수

| 조건 | 기준 | 위반 감지 | 강등 경로 |
|---|---|---|---|
| 도달 답변은 표현 규칙을 지킨다: 결론 문장 선행, 출처·수집 시점 표기, 예상은 범위 표기, 시각물에 결론 문장 부착 | 도달 기준 위반 0 | 도달 전 형식 검사 (기계 판정 가능한 항목만) | 재생성 최대 2회, 소진 시 형식이 검증된 최소 구성(텍스트만)으로 강등 |

근원: CAP-8, L2 §4, H1a. 재생성 중에는 "답변 점검 중" 단계가 표시된다(L2 §6.5) - 검증이 침묵을 늘리면 Q1을 깨기 때문.

### Q4. 기록 무결성 (결정적 경로 - 절대형 허용)

1. 사용자가 동의하지 않은 계획은 기록되지 않는다.
2. 기록된 계획·외부 사정·결과는 유실되지 않으며, 이후 세션에서 항상 조회된다.
3. 확인 시점 경과 여부의 상태 판정은 접속 시점 기준으로 정확하다.

근원: CAP-4, R3·R7, A6·A7·A8.

### Q5. 장애의 정직

| 조건 | 기준 | 위반 감지 | 강등 경로 |
|---|---|---|---|
| 외부 모델 장애·시간 초과는 감지되어 상태로 구분된다 (부분 실패 / 전면 장애) | 감지 후 화면 상태 전환까지 5초 이내 | 호출 실패·타임아웃 신호 | 부분 실패: 미완료 고지 + 부분 답변. 전면 장애: 분석 불가 고지, 기록 열람·단순 조회만 안내. 어떤 경우에도 실패를 가짜 답변으로 메우지 않는다 |

근원: CAP-9, L2 §3·§6.4.

### Q6. 맥락 반영

| 조건 | 기준 | 위반 감지 | 강등 경로 |
|---|---|---|---|
| 기록된 외부 사정은 해당 계획의 이후 분석 입력에 포함된다 | 결과 해석 답변에서 기록된 사정의 인용 확인 (A9) | 도그푸딩 체크리스트 | 미반영 발견 시 결함 처리 (강등 아님 - 구현 수정 대상) |

근원: CAP-6, R7.

### Q7. 중계의 진실성

진행 표시의 각 단계는 실제 수행 중인 작업과 일치해야 한다. 하지 않은 조사를 표시하거나, 표시한 단계를 건너뛰어서는 안 된다. 연출용 가짜 단계는 금지한다.

근원: R5, L0 약속 3(정직)의 화면 이면. 위반 감지: 표시 이벤트와 실제 수행 기록의 대조(L5).

## 2. 품질 속성 우선순위 (경합의 심판 기준)

설계에서 두 품질이 충돌할 때(예: 검증을 강화하면 지연이 늘어남) 무엇이 이기는지를 미리 정한다. L4의 트레이드오프 분석은 이 표를 심판으로 쓴다. 순위의 근거는 L0이다 - 깨졌을 때 제품 존재 이유가 무너지는 순서.

| 순위 | 품질 속성 | 해당 조건 | 근거 | 경합 시 |
|---|---|---|---|---|
| 1 | **근거의 진실성** - 날조 금지, 정직한 실패, 진실한 중계 | Q2, Q5, Q7 | L0 약속 1·3. 깨지면 "근거 있는 컨설턴트"라는 제품 자체가 거짓 | 무엇과 붙어도 이긴다. 느린 진실이 빠른 거짓보다 낫다 |
| 2 | **기록 무결성** | Q4 | L0 약속 2. 깨지면 루프가 성립 안 함 | 결정적 경로라 실질 경합 없음 |
| 3 | **응답성** | Q1 | H4. 깨지면 대화형이라는 형태가 성립 안 함 | 1위에 진다. 단 무한 양보는 아니다 - 재시도 캡과 강등 경로가 지연 폭주를 막는 안전판 |
| 4 | **답변의 완성도·형식** | Q3 | H1a | 3위에 진다. 형식 재시도가 예산을 위협하면 최소 구성으로 강등 |
| 5 | **비용 효율** | §3 | PoC 비목표 | 관찰만. 어떤 품질도 비용 때문에 양보하지 않는다 (운영 단계에서 재순위) |

적용 예: "검증 재시도로 15초가 추가된다 vs 미검증 답변을 즉시 내보낸다" - 1위(진실성)가 3위(응답성)를 이기므로 검증한다. 단 3위 보호 장치로 재시도 캡 2회가 있고, 캡 소진 시 강등은 "거짓을 내보냄"이 아니라 "모른다고 말함"이므로 1위도 지켜진다.

## 3. 판정 방법에 대한 조건 (L5로 넘기는 전제)

외부 모델 출력은 비결정적이므로, 위 조건들의 통과 판정은 **1회 실행이 아니라 반복 실행 표본**(시나리오당 최소 5회)을 기준으로 한다. 측정과 상시 감시의 설계는 L5가 다룬다.

## 4. 이 단계에서 정하지 않는 것

- 동시 사용자·처리량·확장성 (PoC는 단일 사용자 전제, L0 §6.2)
- 보안·개인정보 상세 (실사용자 데이터 없음)
- 비용 상한 (관찰만 한다 - 재시도가 비용을 배수로 늘리므로 호출 수는 기록)

## 5. L4에 거는 요약

L4 설계는 다음을 구조로 증명해야 한다: ① 첫 반응이 외부 모델과 무관한 경로에서 나오는 구조(Q1), ② 도달 전 검증 지점이 존재하는 구조(Q2·Q3), ③ 조사 단계별 시간 초과와 실패가 개별 감지되는 구조(Q1·Q5), ④ 기록이 LLM을 거치지 않고 저장되는 구조(Q4), ⑤ 진행 표시가 실제 수행에서 파생되는 구조(Q7).
