# Documentation Archive

이 디렉터리는 더 이상 현행 설계를 나타내지 않지만, 판단 과정과 구현 역사를 이해하는 데 유용한 문서를 보존한다.

## Archive groups

### `hackathon-prototype/`

Google ADK 해커톤 프로토타입의 루트 안내, 제품 문서, 아키텍처 문서와 프론트엔드 결정을 원래 구조대로 보존한다.

### `orchestrator-v1/`

해커톤 프로토타입 개발 중 이미 대체되었던 초기 오케스트레이터 설계를 보존한다.

### `pre-rebuild-spec/`

Phase 0 확정 전에 작성된 L0~L4 명세 초안이다. 제품 운영 루프와 가상 데이터 중심의 범위가 현재 결정과 달라 아카이브했다.

## Usage rule

- 아카이브 문서는 신규 리빌드의 요구사항이나 계약이 아니다.
- 과거 문제 정의, 설계 근거, 실패 사례를 확인하는 참고 자료로만 사용한다.
- 아카이브와 현행 문서가 충돌하면 [`docs/rebuild/`](../rebuild/)의 결정이 우선한다.
- 아카이브를 수정해 현행화하지 않는다. 새로운 결정은 `docs/rebuild/`에 기록한다.
