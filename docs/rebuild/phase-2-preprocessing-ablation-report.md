# Phase 2: 전처리 노드 실측 실험 및 의도 해체기(IntentParser) 제거 보고서

> **핵심 요약 (BLUF)**:
> 1. **실측 결과**: 전처리 단계에서 텍스트를 재작성하는 IntentParser를 도입한 결과, 인과 맥락 평탄화로 인해 **정확도가 100% -> 50%로 급락**하고 **지연 시간이 15s -> 38s로 250% 폭증**함.
> 2. **결정론적 아키텍처 결단**: IntentParser를 전면 제거하고, 전처리 노드는 **ScopeRouter (비파괴적 스코프 앵커링)만을 단독으로 수행**하도록 아키텍처 확정 (ADR 0007).
> 3. **최종 성과**: 원문 질문의 인과 단서를 보존하고 사전 오버헤드를 없앰으로써 **지연 시간 8.08s (-54.9% 단축) 및 정확도 100%** 회복.

## 2. 왜 의도 해체기(IntentParser)를 제거해야 했는가? (ADR 0007)

1. **단어 고착화(Word Fixation)로 인한 Graph 도구 외면**:
   * 원문의 풍부한 인과 트리거를 운영 메모를 찾고 있습니다로 요약하면서, 에이전트가 단일 문서 플랫 검색(search_documents_semantic)에 갇혀버림.
2. **파이프라인 직렬 지연 시간(250%) 폭증**:
   * 사전 LLM 호출로 인해 23초의 불필요한 레이턴시 낭비 발생.
3. **단일 책임 원칙(SRP) 준수**:
   * 전처리기(ScopeRouter)는 Where/When(세션 스코프 확정)만 담당하고, 자연어 의도 추론과 도구 선택은 본체 에이전트(AgentNode)가 전담함.
