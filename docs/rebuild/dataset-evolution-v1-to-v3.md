# 마케팅 RAG 데이터셋 진화 보고서 (v1 → v2 → v3)

> **핵심 요약 (BLUF)**:
> 1. **v1 (초기 폐쇄계)**: 캠페인당 3문서 폐쇄계로 인한 **Recall 1.0 착시(변별력 상실)** 발생.
> 2. **v2 (광역 얕은 코퍼스)**: 300개 캠페인으로 전역 코퍼스를 열었으나, **캠페인 내부 시계열 깊이(3문서 한계) 부재**.
> 3. **v3 (현행 무편향 고밀도)**: 캠페인당 최대 55개 불균형 시계열 코퍼스 + **2단계 독립 서브에이전트 체인으로 템플릿 누출·오라클 치팅을 100% 제거한 실무 벤치마크 확립**.

## 2. 세대별 발전 배경 및 해결 과제

### ① v1 → v2: "Recall 1.0 착시 타파 및 전역 오답 노이즈 검증"
* **한계**: 캠페인당 3문서 폐쇄계에서는 조잡한 검색기도 무조건 1등을 맞히는 착시 발생.
* **해결**: 300개 캠페인(900문서)으로 전역 코퍼스를 개방하여 타 캠페인 문서 혼입 노이즈 검증.

### ② v2 → v3: "캠페인 내 27개 동종 메모 간 시계열 핀포인트 및 편향성 제거"
* **한계**: 캠페인 내부 문서가 3개뿐이라 "20개 주간 메모 중 7주차 카피 교체 일지"를 가려내는 실무 난이도 측정 불가. 또한 제목 힌트 누출과 오라클 앵커링 편향 존재.
* **해결**:
  1. **불균형 시계열 코퍼스**: 캠페인당 최대 55개 시계열 문서 배치로 실무 난이도 모사.
  2. **Air-Gapped 2단계 서브에이전트**: 코퍼스를 모르는 서브에이전트가 질의를 작성하고 감사관 서브에이전트가 편향을 전수 감사하여 100% 무편향 보증.
