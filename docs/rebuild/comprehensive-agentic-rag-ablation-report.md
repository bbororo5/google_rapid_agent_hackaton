# 종합 실측 보고서: LangGraph 기반 Agentic RAG 파이프라인 구성 및 3단계 어블레이션 검증

> **Executive Summary (BLUF)**:
> 본 보고서는 마케팅 분석 에이전트 시스템을 **순수 LangGraph StateGraph + Gemini 3.7 Flash(Vertex AI ADC) + Arize Phoenix OTel 관측 환경**으로 전환하고, 3단계 점진적 어블레이션(Phase 1 ~ Phase 3) 및 고난도 적대적 스트레스 테스트를 통해 도구와 노드별 실측 효율성과 트레이드오프를 객관적으로 분석한 최종 종합 결산서입니다.

## 2. 현실적 적대적 스트레스 테스트 (Adversarial Stress Test)

유사한 정기 일지 10개 및 광고주 내 복수 캠페인이 경합하는 3대 실무 스트레스 질의에서의 Phase 2 vs Phase 3 비교:

| 고난도 챌린지 케이스 | Phase 2 (Reranker 없음) | Phase 3 (In-Loop Reranker) | 실측 비교 및 분석 |
| :--- | :---: | :---: | :--- |
| **1. 시계열 방해물 충돌 (3월 초순 입찰가 조정)** | 도구 6회 호출 (`45.46s`) | **도구 3회 호출 (`57.37s`)** | **도구 낭비 50% 절감 (탐색 뺑뺑이 억제)** |
| **2. 동일 광고주 내 캠페인 크로스 판별** | 도구 1회 호출 (`5.38s`) | 도구 1회 호출 (`17.57s`) | 두 파이프라인 모두 단독 식별 성공 |
| **3. 지표-조치-회고 3-Hop 결합 추론** | 도구 3회 호출 / 45.27 초 | **도구 1회 호출 / 9.03 초** | **Causal Graph 1회 인출로 지연시간 -80% 단축** |
| **총 도구 호출 수 합계** | **10 회 (불필요한 반복 탐색)** | **5 회 (단 50%의 도구로 해결)** | **고난도 환경에서 도구 호출 50% 절감** |

## 3. 핵심 아키텍처 결론

1. **전처리 계층 (ADR 0007)**:
   * 질문 텍스트를 인위적으로 재작성하지 않고, `ScopeRouter`를 통해 세션 스코프(캠페인 ID, 시간 범위)만 0초 만에 앵커링하는 비파괴적 방식이 가장 안전함.
2. **도구함 계층 (Causal Knowledge Graph)**:
   * 다단계 마케팅 인과 관계를 추론할 때 플랫 검색기의 한계를 극복하고 1회 호출로 체인을 완결함.
3. **자료 정리 계층 (In-Loop Evidence Organizer)**:
   * Reranker는 말단 필터가 아닌 인-루프 정리 노드로 배치할 때, 고난도 방해물 충돌 상황에서 도구 탐색 낭비를 50% 절감함.
