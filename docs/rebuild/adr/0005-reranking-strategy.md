# ADR-0005 — 마케팅 도메인 피처 리랭킹 전략 (MarketingDomainReranker)

> 상태: **채택** · 결정일: 2026-08-19

## Context

마케팅 RAG 검색에서 1차 검색(BM25, Dense)만으로는 다음과 같은 구조적 한계가 존재했습니다:

1. **범용 모델의 도메인 지식 부재**: 범용 사전학습 임베딩/Cross-Encoder는 마케팅 실무 은어("소재 털림", "소진율 페이싱", "CPA 튐")의 의미를 이해하지 못해 랭킹이 뒤로 밀림.
2. **문서 타입 적합도 왜곡**: 마케터가 "지출 급증 원인"을 물었을 때 원인 분석(ANALYSIS)이나 조치 메모(MEMO)가 인출되어야 하나, 어휘 일치율만 높은 기획서(BRIEF)가 1위로 인출되는 문제.
3. **에이전트 다단계 루프의 지연 증폭**: 에이전트가 1개 질의 해결을 위해 도구를 2~3회 연쇄 호출할 때, 무거운 Cross-Encoder(회당 200ms+)는 전체 응답을 1.5~2초 이상 지연시키는 트레이드오프 발생.
4. **블랙박스 점수의 감사 불가능성**: 엔터프라이즈 마케팅 의사결정 환경에서 왜 특정 문서가 1위로 추천되었는지 사후 감사 및 디버깅이 불가능한 한계.

## Options

| 리랭킹 후보 | 도메인/의도 적합도 반영 | 설명 가능성 (Auditability) | 에이전트 루프 레이턴시 | 서빙 복잡도 / 비용 |
| :--- | :---: | :---: | :---: | :---: |
| **MarketingDomainReranker (채택)** | **우수 (타입 가중치 w3=0.15 및 동의어 매칭)** | **우수 (컴포넌트 점수 분해 추적)** | **1~3ms (초저지연)** | **매우 낮음 (인프로세스 실행)** |
| **Cross-Encoder (bge-reranker)** | 보통 (일반 상식 중심, 마케팅 은어 취약) | 불가능 (블랙박스 로짓) | 150~300ms (다단계 시 1초+) | 높음 (전용 GPU 서빙 필수) |
| **No Reranker (1차 검색 단독)** | 미반영 (1차 점수 순위 그대로 노출) | 보통 | 0ms | 없음 |

## Decision

- **다차원 피처 결합 MarketingDomainReranker 채택**:
  $$S_{\\text{final}} = w_1 \\cdot S_{\\text{bm25}} + w_2 \\cdot S_{\\text{dense}} + w_3 \\cdot S_{\\text{domain\\_feature}}$$
  1. **문서 타입 적합도 주입 (w3 = 0.15)**: 질의 의도(원인 분석 vs 운영 조치 vs 기획)와 문서 메타데이터(BRIEF / MEMO / ANALYSIS) 간의 정합도 점수를 직접 반영하여 엉뚱한 기획서 우선 노출을 차단.
  2. **마케팅 은어 동의어 교정**: 실무 어휘("소재 피로", "소재 털림", "페이스 조절") 매칭 피처를 결합하여 임베딩 공간 왜곡 보정.
  3. **초저지연 인프로세스 실행**: 에이전트 다단계 도구 호출 환경에서도 1~3ms 내에 즉각 연산 완료.
  4. **결정론적 점수 감사 지원**: 키워드 점수, 임베딩 점수, 도메인 피처 점수가 각각 분해되어 로그에 남으므로 오답 랭킹 발생 시 100% 원인 추적 가능.

## Empirical Evidence (Golden Dataset v2)

- **Dense 검색기 보정**: 마케팅 은어에 취약했던 Dense MRR을 **0.2473에서 0.5323으로 +28.5%p 대폭 견인**.
- **Hybrid 최종 수렴**: 1차 Hybrid 검색기와 결합 시 **MRR 0.6173 / nDCG 0.6187**을 기록하며 전체 12개 파이프라인 조합 중 압도적 1위 달성.
