## 결정

분석 경로를 다음으로 구성한다.

1. **조사 3종(지표 조회, 트렌드 검색, 노하우 검색)을 질문과 무관하게 항상 전부, 병렬 실행한다.** 조사는 LLM 호출이 아니라 결정적 데이터 조회(코드)다.
2. **생성 LLM 호출 1회**가 대화 전체 기록 + 재료 전부를 받아 답변을 작성한다. 분석형 턴당 LLM 호출은 이 1회뿐이다.
3. 게이트(F4, 코드)가 검증하고, 불합격 시 사유를 붙여 재생성한다(캡 2회). **루프는 이 게이트 재시도뿐이며, 조사 단계의 재회귀(결과를 보고 다시 조사)는 없다.**
4. 즉답 경로(단순 조회)는 이 경로를 우회한다.

"무엇을 조사할지 고르는 판단"과 "결과를 보고 다시 고르는 판단"을 **만들지 않는 것**이 이 결정의 본질이다. 서랍이 3개뿐이고 전부 열 수 있는 동안, 고르는 기계는 낭비다.

## 오해 방지 (토론에서 나온 것)

- **대화의 자유와 무관하다.** 이 결정은 질문 하나를 처리하는 몇십 초 동안의 내부 동선이다. 사용자가 무엇을 어떤 순서로 묻는지는 L2(자유 텍스트 단일 채널)가 정하며, 생성 호출이 대화 전체 기록을 받으므로 답변은 자유 대화로 이어진다.
- **"전수 실행 = 호출 폭증 / 지연 증가"가 아니다.** 조사 3종은 LLM이 아니라 내부 데이터 조회(DB·검색, 밀리초~수초)이며 병렬이라 총 시간은 셋의 합이 아니라 가장 느린 하나다. 외부 LLM 의존은 생성 1회뿐이다. 시간표 비교:

  ```
  채택안:   [조사 3종 병렬 1~3초, 내부] → [생성 LLM 10~30초, 외부 1회] → [게이트 ~0초]
  선택형(b): [라우팅 LLM 2~5초, 외부] → [조사 1~3초, 내부] → [생성 LLM 10~30초, 외부]  ← 외부 의존 2회
  ```

  조사를 골라 줄여도 병렬 구간(1~3초)은 줄지 않고, 병목(생성 10~30초)은 양쪽에 동일하다. 선택형이 오히려 외부 지연·장애 의존을 1회 추가한다. 선택이 유효해지는 유일한 조건은 재료가 커져 생성 입력이 무거워질 때 - 아래 진화 트리거 그 자체.
- **게이트는 조사의 약점을 메우지 않는다.** 게이트는 거짓(날조·형식 위반)이 나가는 것을 막는 문지기이고, 조사 고정의 약점은 "틀린 답"이 아니라 "모른다는 답"으로 나타난다. 1순위 가치(진실성)는 유지된다.

## 기각한 대안

- **(a) 단일 에이전트 + ReAct (모델이 도구를 골라가며 도는 루프):** 우선순위 1위 진실성에서 열세 - 조사 실패가 모델의 사고 루프에 흡수되어 정직한 실패(Q5)가 모델 재량에 남고, 진행 중계(Q7)의 해상도가 낮다. 3위 응답성 열세 - 순차 왕복마다 모델 추론 시간. 4위 형식 열세 - 만능 프롬프트의 이행률 저하.
- **(b) 코디네이터 (모델이 조사를 고르고, 결과를 보고 재조사 가능):** 채택안과의 실차이는 "고르기"와 "재회귀" 능력뿐인데, 전수 인출이 가능한 현 규모에서 두 능력의 이득이 0에 수렴한다(전부 가져오면 고를 것도, 다시 가져올 것도 없다). 비용(호출 수·조율 복잡도·루프 폭주 위험)만 실재. **기각이 아니라 유예** - 아래 진화 트리거의 도착지.

한 줄 근거: **복잡성은 미리 사두는 자산이 아니라, 필요가 증명될 때 지불하는 비용이다** (최소 권력의 원칙, 갈의 법칙, Anthropic 워크플로/에이전트 지침, 최후 책임 시점, 되돌리기 비대칭이 모두 같은 방향).

## 확장·축소 조항: "개수는 목록이 알고, 코드는 모른다"

- 모든 조사는 단일 규격을 따른다: 입력(질문 맥락, 캠페인 ID) → 출력(재료 + 출처 ID + 수집 시점 + 성공/실패). 실행부는 조사 **목록(레지스트리)** 을 순회해 전부 병렬 실행하며, 개수를 알지 못한다.
- **확장:** 새 조사 추가 = 목록에 항목 추가. 병렬 실행·진행 표시·게이트 대조·프롬프트 조립은 개수 무관.
- **축소:** 목록에서 제거 = 끝. 빈 재료는 "모른다"(R6)로, 실패는 부분 실패 고지(Q5)로 이미 흡수된다.

## 진화 트리거

이 결정의 유효 조건은 **"재료 전부를 생성 호출 하나에 넣을 수 있다"**이다. 조사 종류 증가 또는 표본 규모 증가로 전수 인출이 컨텍스트 용량·비용·Q1 예산을 깨는 순간, **코디네이터(모델이 목록에서 고르고, 재회귀 판단)로 전환한다.** 그때 조사 레지스트리와 규격은 그대로 재사용된다 - 코디네이터는 같은 목록에서 고르는 존재일 뿐이다. 질문 유형별 고정 코스(코드 분기)로의 확장은 L0 원칙 관문 불합격이므로 금지.

## 파급

- L4 O3(조사 계획 주체) 소멸 - 코디네이터 전환 시 부활.
- 조사 규격·레지스트리가 O5(데이터 스키마)의 입력이 된다.
