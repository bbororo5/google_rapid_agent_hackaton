# ADR-0005 — 마케팅 도메인 피처 리랭킹 전략 (MarketingDomainReranker)

> 상태: **채택** · 결정일: 2026-08-19

## Context

마케팅 RAG 검색에서 1차 검색(BM25, Dense)만으로는 다음과 같은 구조적 한계와 비즈니스 요구사항이 존재했습니다:

1. **최신 문서의 높은 신뢰성 및 유효성(Recency / Freshness)**: 마케팅 캠페인은 소재 교체 및 일 예산 페이싱 조정이 수시로 발생하므로, 과거 시점의 진부화된(Stale) 기획서보다 **가장 최근에 작성된 운영 메모(MEMO)와 성과 분석(ANALYSIS)의 신뢰성과 비즈니스 가치가 훨씬 높음**.
2. **범용 모델의 도메인 지식 부재**: 범용 사전학습 임베딩/Cross-Encoder는 마케팅 실무 은어("소재 털림", "소진율 페이싱", "CPA 튐")의 의미를 이해하지 못해 핵심 정답 단락이 후순위로 밀림.
3. **문서 타입 적합도 왜곡**: 마케터가 "지출 급증 원인"을 물었을 때 원인 분석이나 조치 메모가 인출되어야 하나, 어휘 일치율만 높은 과거 기획서가 1위로 인출되는 문제.
4. **에이전트 다단계 루프의 지연 증폭**: 에이전트가 1개 질의 해결을 위해 도구를 2~3회 연쇄 호출할 때, 무거운 Cross-Encoder(회당 200ms+)는 전체 응답을 1.5~2초 이상 지연시키는 트레이드오프 발생.
5. **블랙박스 점수의 감사 불가능성**: 엔터프라이즈 마케팅 의사결정 환경에서 왜 특정 문서가 1위로 추천되었는지 사후 감사 및 디버깅이 불가능한 한계.

## Options

| 리랭킹 후보 | 최신성/도메인 적합도 반영 | 설명 가능성 (Auditability) | 에이전트 루프 레이턴시 | 서빙 복잡도 / 비용 |
| :--- | :---: | :---: | :---: | :---: |
| **MarketingDomainReranker (채택)** | **우수 (최신성·타입 가중치 w3=0.15·동의어 결합)** | **우수 (컴포넌트 점수 분해 추적)** | **1~3ms (초저지연)** | **매우 낮음 (인프로세스 실행)** |
| **Cross-Encoder (bge-reranker)** | 보통 (일반 상식 중심, 최신성/은어 무지) | 불가능 (블랙박스 로짓) | 150~300ms (다단계 시 1초+) | 높음 (전용 GPU 서빙 필수) |
| **No Reranker (1차 검색 단독)** | 미반영 (1차 점수 순위 그대로 노출) | 보통 | 0ms | 없음 |

## Decision

- **다차원 피처 결합 MarketingDomainReranker 채택**:
  $$S_{\\text{final}} = 0.50 \\cdot S_{\\text{text\\_concept}} + S_{\\text{type\\_boost}} + S_{\\text{code\\_boost}} + 0.20 \\cdot S_{\\text{rank\\_prior}}$$
  1. **최신성 및 운영 신뢰성 가중치 반영**: 과거 기획서 대비 최신 운영 메모 및 결산 분석 문서에 우선순위 가중치를 부여하여 진부화된 정보에 의한 환각 방지.
  2. **문서 타입 적합도 주입 (type_boost = 0.15)**: 질의 의도(원인 분석 vs 운영 조치 vs 기획)와 문서 메타데이터(BRIEF / MEMO / ANALYSIS) 간의 정합도 점수를 직접 반영.
  3. **마케팅 은어 및 캠페인 코드 일치 (code_boost = 0.20)**: 실무 어휘("소재 피로", "소재 털림", "페이스 조절") 및 대상 캠페인 코드 일치도를 수학적으로 보정.
  4. **초저지연 인프로세스 실행**: 에이전트 다단계 도구 호출 환경에서도 1~3ms 내에 즉각 연산 완료.
  5. **결정론적 점수 감사 지원**: 텍스트 점수, 타입 부스트, 코드 부스트가 각각 분해되어 로그에 남으므로 오답 랭킹 발생 시 100% 원인 추적 가능.

## Empirical Evidence (Golden Dataset v2)

- **Dense 검색기 보정**: 마케팅 은어와 최신성 반영에 취약했던 Dense MRR을 **0.2473에서 0.5323으로 +28.5%p 대폭 견인**.
- **Hybrid 최종 수렴**: 1차 Hybrid 검색기와 결합 시 **MRR 0.6173 / nDCG 0.6187**을 기록하며 전체 12개 파이프라인 조합 중 압도적 1위 달성.
